登录不校验密码、角色来自页面选择；报告中存在前端判定函数。它们当前是展示原型。

## 3. 与 V1.3 对齐时必须处理

1. **自动对焦**：方案弹窗、报警中仍有自动对焦/校准，V1.3 已明确人工固定调焦。
2. **相机角色**：保持预览布局，建立到 A/B/C/D、E、F、3D 的明确映射；不把原型 CAM-01 等数字直接当最终硬件点表。
3. **状态与质量分开**：算法/相机错误、质量 NG、Pending 与分拣完成不能混为同一类报警或“检测成功”。
4. **停止按钮**：屏幕按钮只能请求软件/设备停止并展示实际反馈；实体急停与硬件安全回路单独测试，
   不能让浏览器按钮承担硬件急停保证。建议正式标注“停止”或“请求停止”，实体急停状态另显示。
5. **判定来源**：正式 OK/NG/Pending 来自后端 Quality；不能按页面硬编码阈值判定，不能由缺失结果默认OK。
6. **真实参数**：相机型号、PLC型号/IP、曝光、容差、模型名、GPU编号、1.8秒/96.4%等仅为原型样例，不能自动冻结。
7. **权限**：角色由后端账户决定，前端切换 L3 不能提升权限；计划运行中编辑新版本不能修改当前任务快照。
8. **MES**：未配置/未启用应显示相应状态，不能默认把未交付 MES 展示为核心故障。
