日期：2026-09-17。主项目：`NickYoung618/x`，业务和验收基准为总体架构 V1.3。

## 结论

**现有虚拟下位机具备可复用的通信、设备动作、监控和故障模拟基础，可以开展接入。
尚不能认定它已满足 V1.3 普通整盘全虚拟验收，也不能直接用旧测试全绿作为完整合并/发布条件。**

无需重做整个模拟器。应保留其设备实现，针对以下明确差异完成接入规格、接口版本对齐和测试修订。
本轮只读远端项目，在本机独立副本构建和运行，没有修改远端源码或中台运行代码。

## 3. 实际验证及条件

### 3.1 构建与运行

本机使用 Linux x64、.NET SDK 10.0.401、运行时 10.0.12。
主项目未经源码修改执行 `dotnet publish src/VirtualPlc/VirtualPlc.csproj -c Release` 成功，
真实启动发布目录中的 DLL，健康、HTTP 和 Modbus 行为可用。
已核对快照原有文件的哈希未改变；所有构建、测试输出及审查驱动在独立临时目录内。

### 3.2 原有 13 组检查

**原有 13 组检查在 .NET 10 发布主机上全部通过，测试源码和断言未修改。**
驱动条件有所调整：原验证程序目标是 net8.0，本机未装 .NET 8；
用独立的 net10.0 项目链接原测试源码，并保持 C# 12（原 net8.0 默认语言版本）。
因此不是“原 validate.sh 原样通过”，也不是 Windows 平台测试。

- [逐组结果](suite-net10.md) / [JSON](suite-net10.json) / [执行输出](suite-stdout.log)。
- [运行环境与进程清理记录](review-summary.json) / [主机日志](host-net10.log)。
- [独立驱动项目](ReviewDriver.csproj) / [运行脚本](run_review.py)。
  二者保存作复现参考，依赖源快照和本文记录的目录布局，并非已接入仓库的通用 CI 入口。

这 13 组中含旧流程策略校验，`POLICY-01` 明确断言扫码/保存失败继续是“正确”。

### 3.3 保留的失败与限制

| 尝试 | 实际结果 | 影响及处理 |
| --- | --- | --- |

| 直接以构建参数覆盖驱动框架 | 仍在还原 net8.0 依赖时失败 | [日志](attempt-framework-override.log)；未将失败算通过 |
| 随后误启动尚未生成的测试驱动 | 驱动缺失，suite 退出 1；主机启动和策略接口探查成功 | 保存 [首次尝试记录](failed-attempt-1/review-summary.json)，不计为已执行 13 组测试 |
| 独立 net10.0 驱动默认语言版本 | 编译失败 CS4007，原测试第 258 行 SequenceEqual 与 await 涉及 Span 跨等待 | [日志](attempt-driver-csharp14.log)；这是改变测试框架/语言后的兼容问题，不据此宣称原 net8.0 程序不能构建 |
| 独立 net10.0 驱动 + C# 12 | 0 warning / 0 error，运行 13/13 通过 | [构建日志](driver-build-csharp12.log)；保持原源码与断言，未修改模拟器业务代码 |

CI 可选择安装并固定 .NET 8 测试驱动依赖与 .NET 10 主机依赖，或正式迁移测试程序并验证。
无论采用哪种方式，.NET 10 主机的构建必须单独成为必需检查。
现有测试总评只汇总检查项，允许生产构建为 NOT RUN 时仍返回 PASS；不能直接拿这个总评当发布门槛。

## 5. 最小接入顺序

1. 建立“现有 VirtualPlc 接入与 V1.3 对齐”规格，引用此清单、已有 Spec Kit 资料与共同契约。
2. 第一条 PR 可交付独立设备源码和可运行构建/旧协议测试，清楚标记旧协议范围，不宣称整盘完成。
3. 后续 PR 修正业务辅助策略、统一编码/握手、补分拣状态和动作轨迹，逐项加入针对性验收。
4. 中台实际 Modbus 客户端连接该进程；测试控制接口只用于布置场景、注入故障和核对状态。
5. 普通整盘执行链、采集/算法模拟及 Vue/WPF 就绪后，生成统一 Windows FullSim 候选包并验收。

已关闭远端 SSH 会话和本轮自己启动的模拟器进程；远端现有服务未被启动、重置、注入故障或停止。
本轮未推送、合并、修改仓库权限或发布 Release。协作流程见 [团队指南](../../team-development-and-release.md)。
