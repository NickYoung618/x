## 全虚拟首版的完成标准

用发布后的程序，从原型对应登录页进入，选择测试检测方案，启动完整普通件托盘任务。
确认初扫 → 面1 A1/A2/B1/B2 → 整盘一轮翻面 → 重扫 → 面2 A1/A2/B1/B2 →
所有必检任务终态 → 单件判定 → NG/Pending 分拣 → 必要保存核对 → 允许放行。
算法可后台推进，以上箭头不要求普通缺陷计算阻塞机械；软件保存意图须在相应物理动作之前。
每条图像和结果能追溯到相同 TrayRunId/PartId/Face/CaptureSet/Attempt，且重开软件查询仍存在。

特殊件模板在该普通件切片后扩展。V1.3 全部 P1 内容包含更多模板及维护能力，
完成普通件切片不能把 V1.3 全部 P1/P2/真机验收勾为完成。
