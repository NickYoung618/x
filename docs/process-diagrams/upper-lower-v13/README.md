# 上下位机对接图：仓库内可复核副本

本目录的 11 份 SVG 从本机 `/home/ubuntu/disk/yyh/架构设计.zip` 内的 `架构设计/上下位机对接.zip` 逐字节提取；来源、压缩包及逐文件 SHA-256 见 [source.json](source.json)。同名 PNG 是 SVG 的展示副本，未重复入库。图是用户指定的**真实流程首要依据**；[V1.3 架构](../../architecture/architecture-v1.3.md)确定软件模块边界，并补充图中未画出的状态、重扫、恢复和验收要求。图不是已经签认的 PLC 点表、相机参数或生产配方。

| 图 | 对设备侧实现的直接要求 |
| --- | --- |
| [上下位机职责边界图](上下位机职责边界图.svg) | PLC 管安全、实体按钮、夹紧、轴/机构运动和实际反馈；上位机管工单、配方、触发、识别、判定和追溯。 |
| [安全与实体按钮处理流程图](安全与实体按钮处理流程图.svg) | 安全检查 → 等实体按钮 → 夹紧确认 → 自动运行；条件失败要拒绝并反馈，运行中急停/开门/气压异常须终止危险动作。 |
| [整体流程图](整体流程图.svg) | 初始 3D → F 料盘码 → 配方 → 普通/特殊件 → 分拣 → 下料松夹的总路径。 |
| [总时序图](总时序图.svg) | 137 步顺序，覆盖动作下发、轴/机构实际到位、相机触发、反馈与人工上下料；上位机在到位后触发相机。 |
| [相机与轴组关系图](相机与轴组关系图.svg) | A/B/C/D 共用成像 Z、E 独立 Z；XY、取放 Z、夹紧、翻面、旋转、分拣分别可观测。 |
| [采集动作逻辑图](采集动作逻辑图.svg) | 3D/F/E/A/B/C/D 各有目标位与到位要求；相机和光源触发归上位机。 |
| [单零件检测闭环图](单零件检测闭环图.svg) | 普通件 A/B 或 C/D、翻面、必要时 E 扫码与结果闭合；整盘执行次序按 V1.3 §5.3 明确的“逐相机全盘批采”。 |
| [特殊零件类型判断图](特殊零件类型判断图.svg) | 配方判断普通/特殊；图只展开类型 1，不能凭图推断类型 2–4 的物理动作参数。 |
| [特殊零件单个闭环流程](特殊零件单个闭环流程.svg)与[检测闭环图](特殊零件单个检测闭环图.svg) | 取料至旋转位、旋转、选相机组、按 OK/NG/Pending 整体放料；PLC 内部取放动作不由 PC 逐拍控制。 |
| [分拣动作单独闭环图](分拣动作单独闭环图.svg) | PC 选择去向并给取/放目标，PLC 执行整体取放并给匹配的完成/失败反馈。 |

解释边界：总时序图在翻面后写“进入下一检测面”，未单独绘制 3D 重扫；V1.3 §5.3 已明确“整盘翻面后必须重扫”，现按补充步骤建模，不能静默删掉。图中 3D 相机返回点云/深度数据，上位机完成定位；设备模拟器与中台定位器必须分层，不能用模拟器直接给槽位代替完整采集链。类型 2–4 的组合只在 V1.3 给出模板方向，具体取放、角度和采集参数仍须配方/机构资料。任何数值地址、字序、坐标单位、实际位置、停止/恢复行为，都要在[全工位下位机派任书](../../assignments/plc-all-stations-parallel-work-order-20260917.md)所要求的版本化合同中确认。
