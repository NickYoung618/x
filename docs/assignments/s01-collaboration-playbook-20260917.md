# S01 首工位：中台与下位机协作执行单

本页供双方照着开工和对账；正式工作范围见[下位机派任书](s01-plc-work-order-20260917.md)，业务时序见[工位合同](../../specs/005-initial-3d-station/contracts/station-boundary.md)，逐场景期望见[测试矩阵](../../specs/005-initial-3d-station/test-matrix.md)。当前 [S01 PR #7](https://github.com/NickYoung618/x/pull/7) 为 Draft：中台调用侧已实现并通过端口替身测试，独立 PLC/3D 模拟、V1.3 Modbus 对接尚未通过。

## 1. 第一轮只交 S01，不等配方或算法

S01 的唯一正常终点是 `WaitingTrayCode`：本盘新鲜 Ready、夹紧且互锁清除，中台下发一次公共 3D 位移动，下位机先回受理再回实际到位；中台此后调用一次独立 3D 模拟器，得到可追溯的合成槽位和位置引用，建立坐标批次并发出 F 请求。F 读码、真实点云算法、配方、翻面、分拣和整盘均在后续增量，不能用这些尚未完成的能力阻塞 S01 的软件联调，也不能把 S01 成功写成整盘通过。

| --- | --- | --- |
| 中台同学 | 已有 `IReadyObserver`、`IMotionDevice`、`IPlacementLocator` 调用语义，Host 工程入口、S01 状态/错误码与 N01/P/M/S 测试矩阵；后续负责 3D 调用客户端、Host 装配与两侧轨迹对账 | 下位机同学以这些请求/结果字段提出设备侧合同；前端只调 Host，不直连设备 |

## 2. 双方按这四次交接推进

1. **合同草案**：下位机同学先提交 D1 和 D2b 协议提案。PLC 每个字段至少写名称、读/写方向、功能码、地址基数及进制、数据类型/字序、单位、合法范围、刷新/过期规则、复位规则；附一个已知数值的原始寄存器字节例子。3D 至少写启动端口/协议、请求与结果字段、RequestId/TrayRunId/Epoch 回显、超时/错 ID/断连表示、故障注入方式和日志格式。没有依据的数字地址、Float32 字序、物理坐标或相机参数一律写“待双方确认”，不猜。
2. **合同评审**：中台同学用同一字节例子独立解码，逐项核对 Ready 新鲜度、`OperationId` 与设备命令号如何关联、Accepted 与 Completed 的先后、停止/断线/重连对账，以及 3D 请求/结果的身份和坐标来源。只冻结 S01 需要的字段；有争议的字段留在差异表，未签认前不向真机发动作。
3. **两个模拟进程和接入**：下位机同学提供干净环境的锁定依赖还原、`dotnet build`、启动/退出命令及场景配置；中台接入后，从 Host 工程入口启动每个用例。PLC 业务调用必须实际经过中台 Modbus 客户端；3D 必须实际调用另一进程。控制端口只负责给模拟器预置设备事实和故障，不能替中台宣告动作成功。
4. **联合复核**：每个用例保存输入、预期、Host 响应/错误、Host 轨迹、PLC 原始通信和独立动作轨迹、3D 请求/结果轨迹、实际运动和采集次数、软件版本/提交/合同版本。双方对同一 `TrayRunId`、`OperationId`、`RequestId` 和时间顺序签收。失败先定位哪一侧偏离，再在原用例复测；不得把旧 V6 测试或端口替身测试算作 V1.3 跨进程通过。

## 3. 双方第一次一起跑的两个例子

**N01 正常**（这里的 ID 和槽位只是固定测试数据，不是物理地址）：给虚拟 PLC 预置本盘新鲜 Ready、已夹紧、互锁清除；给 3D 模拟器预置两个有效合成槽位。中台以 `TrayRunId=tray-s01-001` 开始；PLC 轨迹应见一次公共 3D 位移动及其唯一动作标识。收到 Accepted 时 3D 请求数仍为 0；收到匹配的 Completed 后，3D 轨迹恰有一次同盘、同 RequestId、`Epoch=1` 的请求与两个槽位结果。Host 终态是 `WaitingTrayCode`，两个 PartId 唯一，F 请求数为 1、F 实际执行数为 0。双方核对移动 1 次、3D 1 次，不允许靠 Host 自己的日志代替设备计数。

**M02 超时**：给虚拟 PLC 预置“受理后不返回可信完成”。中台仍只发送一次移动；期限到达后 Host 为 `RecoveryRequired`，3D 请求数 0、F 请求数 0。随后恢复通信，也不能自动重发或把旧完成当本次到位；必须先读设备实际状态并对账。对应完整矩阵还要覆盖未就绪/互锁、明确拒绝、断线、错/早/重复完成、3D 超时/坏槽/错盘/迟到，以及诊断写入失败。模拟器无法安全表达的物理故障记明 `NOT RUN`，不制造真机危险动作。
