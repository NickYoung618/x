# 全工位下位机并行先行工作派任书

**编号**：GAODE-PLC-ALL-20260917。**执行方**：下位机／虚拟 PLC 同学。**协作方**：中台、前端、设备/现场人员。

用户已指定[《上下位机对接》11 组图](../process-diagrams/upper-lower-v13/README.md)为真实流程的首要依据；[V1.3](../architecture/architecture-v1.3.md)确定模块责任和图中未详述的要求。下位机同学现在可**一次规划并提前完成全流程设备侧软件**，中台继续按[S01–S11 工位](../station-delivery-order.md)独立 PR 开发；双方只在版本化合同和每个工位的联调门槛会合，不再等待“中台先做完一站、下位机再做这一站”。本单改变下位机的开发顺序，不把所有中台工位合成一个大 PR。

**最新接口来源**：用户进一步指定[2026-09-11《PLC与上位机通信接口协议》及逐点差异](../contracts/plc-upper-20260911.md)为接口定义基准。`pj/HousingInspection` 的 008 接口和现有 `simulator/VirtualPlc/` 使用 SRS V6 点表，只能作为旧协议回归；下位机同学应据新合同修订新版模拟器/机械动作扩展，不应让中台继续按 V6 单字坐标或角度翻面接入。

## 一、交付范围与职责边界

下位机同学负责全流程 PLC/运动侧：安全检查与实体按钮、夹紧/松开、XY/成像 Z/E Z/取放 Z、移动到 3D/F/A/B/C/D/E/旋转/分拣/下料位、翻面、旋转、整体取放/分拣、运行状态、停止/故障、重连对账。交付独立虚拟 PLC、与真实设备共用的版本化 Modbus 适配及测试驱动；按已确认分工，另交付**独立 3D 相机接口模拟进程**，提供确定性的合成点云/深度数据或可读取的固定帧引用及设备故障。中台负责将这类模拟采集输入转换为槽位/位置引用；真实定位算法和标定另验。虚拟 PLC 不生成扫码内容、缺陷结论或随机质量判定；F/E/A–D 相机触发、帧/码模拟与调用客户端由中台采集侧负责，算法、配方、工件身份、OK/NG/Pending 决策、目标槽位选择及持久化也归中台。PLC 保留实体互锁和动作内部闭环。

| 设备能力包 | 图中的正常动作与必须反馈 | 至少预置的独立故障/恢复场景 |
| --- | --- | --- |
| L0 启动/安全 | 安全检查、实体启动按钮、夹紧到位、自动/手动、心跳；异常必须拒绝新动作 | 未按按钮、门/急停/气压异常、未夹紧、失联、停止后实际状态查询 |
| L1 公共准备 | 移至 3D 位并实际到位；随后移至 F 位；3D 相机模拟器接收同盘触发并返回合成点云/深度帧或固定引用，中台模拟定位器再得槽位/姿态/位置引用 | Accepted 未到位、错/旧完成、3D 超时/错盘、F 位失败 |
| L2 普通采集 | 按 PC 给的目标逐槽移动到 A/B/C/D 位及其成像 Z，给到位/失败；E 位与独立 E Z 到位 | 越界、Z 未到位、通信断开、重复命令/旧反馈、E 位失败 |
| L3 翻面与重扫 | 接受包含取/放目标和目标面的整体翻面任务，反馈机构实际终态；翻面后可再次移到 3D 并重扫 | 抓取/放置失败、夹爪未知、执行中断、重连后不能确定是否已翻 |
| L4 特殊件 | 整体取料到旋转位、指定角度旋转、按 A/B 或 C/D 到位、从旋转位整体放到 PC 指定目标 | 旋转未到位、夹具占用、放料失败、重复执行保护；类型 2–4 未确认参数不得猜 |
| L5 分拣/结束 | 对 NG/Pending 等 PC 已选目标执行整体取放、反馈占用/终态；移动到下料位、松夹、待机灯状态 | 目标满/不可达、抓空/抓取未知、反馈丢失、松夹禁止条件 |

所有能力包均须提供唯一动作关联、明确的 `Accepted`／`Completed`／`Failed`／`Unknown`、实际执行次数和独立设备轨迹。`Accepted` 只表示接收，不代表物理到位；未知动作不得自动重发。图中只写“到位/完成”的位置，也须在合同中定义可观测条件及超时/错误。

动作清单至少包括 `SafetyCheck`、`ClampTray`、`MoveTo3D`、`MoveToF`、`MoveToCapture(A/B/C/D)`、`MoveToE`、`FlipPickPlace`、`TransferToRotation`、`Rotate`、`TransferFromRotation`、`SortPickPlace`、`MoveToUnload`、`ReleaseTray`、`StopAndReconcile`。这些是**逻辑任务名**，不是已定的线圈/寄存器编号；可用一套带动作类型与参数的命令区实现。每个任务都要列调用方提供的目标/面/角度/源和目标位置、PLC 锁存的参数、关联反馈与实际位置/夹爪/互锁状态；不适用字段明确写“不适用”。模拟测试可使用固定目标引用，真机协议须给完整数值、单位、范围及安全边界。

## 二、先交全量合同，再并行编码

1. **第一份可评审产物**：`docs/contracts/plc-v13-all-stations-v0.1.md` 草案和动作清单。逐项对应 L0–L5、所据图及总时序步骤，列命令输入、设备锁存、受理/完成/失败、当前物理状态、停机/恢复、错误码、超时。点表列地址进制与零/一基、功能码、寄存器宽度、字/字节序、数值单位/范围和原始报文字节例子；先标未决，不编造生产数值。另给 3D **采集**请求/点云或深度帧引用及故障注入协议，不把直接返回槽位当相机线路协议。中台在合同 PR 上逐字段回复，冻结一个版本后双方并行实现。
2. **不必等中台逐站实现**：沿用已有 `simulator/VirtualPlc/`，按 L0–L5 开发独立虚拟 PLC 和自测客户端；增加独立 3D 模拟进程。模拟器使用可配置端口/固定场景，不依赖 Host 的内存状态机。中台可凭草案开发语义端口、F/E/A–D 采集模拟和流程，即使下位机全量软件尚未完工。
3. **适配与联合验收**：下位机同学提交 `Inspection.Infrastructure` 的版本化 Modbus 编解码/设备适配，中台审查并装配 Host。每站只换已发布合同/模拟器版本，真实业务经中台 Modbus 客户端和独立 3D 客户端通信；管理 API 仅预置设备事实，不冒充业务动作。各站继续单独 PR 和测试；下位机软件可以按 L0–L2、L3–L5 分批 PR 合入，不必积压为一个不可评审的大提交。
4. **实际设备**：完成点表/固件/机械包络/互锁和现场准入签认后，使用同一候选包在实际 Windows 电脑从只读状态逐步验证。没有真实型号、位置、标定、样件时，可以完成软件合同与模拟验收，不能称真机工艺或精度通过。

## 三、交付的最小证据与双方回执

下位机提交：合同版本和差异表、源码/提交/PR、.NET 10 锁定还原与发布/启动命令、固定场景输入、原始 Modbus 报文与预期值、L0–L5 正反例自动测试、独立动作轨迹（会话/命令号、参数、受理/实际终态、时间、次数、物理位置/夹爪/互锁）、Linux/Windows 干净环境 CI 结果、未决项和现场设备版本。3D 模拟器另交请求/结果轨迹和准确触发次数。旧 V6 回归单独列，不计入 V1.3 通过。

中台在收到**全量合同草案**后即逐字段评审，给出能接收的语义端口/拒绝原因，并继续每个工位的状态机、相机/算法替身和 Host 测试；收到已发布设备版本后按该工位的正常、拒绝、迟到、错 ID、超时、断线及恢复矩阵做跨进程复测。双方用同一 TrayRunId、OperationId、命令序号、RequestId 和设备实际计数对账。全流程虚拟验收还需要 F/E/A–D、算法、配方、数据与桌面侧，不能由下位机自测代替。

提交策略：下位机从最新 `main` 建独立 `plc-all-stations` 功能分支；合同可先独立 PR，设备软件按能力包 PR 合并。中台的 [S01 Draft PR #7](https://github.com/NickYoung618/x/pull/7) 继续只验收 S01，后续 S02–S11 各自 PR。某设备能力未交付时对应工位记 `BLOCKED`，已完成能力可先被另一站消费；不得为了“全部完成”掩盖未测项。

## 四、目前需明确但不阻止全量模拟开发的项

- 旧 V6.0 与 2026-09-11 点表不兼容；地址表示、Float32 字序/单位、成像/扫码/取放 Z、会话和命令号、停止/重连对账、面号/角度、取放坐标与复位责任须双方签认。未定时仅可用版本化合成合同，不驱动真实设备。
- 总时序图没有画出翻面后 3D 重扫；V1.3 §5.3 明确要求重扫并保留 PartId、更换 CoordinateEpoch，先按该补充实现。若设备方认为机构不支持，需反馈具体限制和替代对账方案，不能静默跳过。
- 图仅展开特殊类型 1；类型 2–4 的实际角度、抓取/放置步骤、相机组及目标位依赖配方和机械资料。先实现通用旋转/整体取放能力和确定性模拟样例，不制造生产配方。
- 3D 真机 SDK、型号/标定、工件及真实坐标不在图中；独立 3D 接口模拟可先完成，真机与定位精度另验。
- 现有 S01 调用端口 `IPlacementLocator` 返回槽位，是**中台定位结果**的上层语义；其下方的相机模拟器应返回采集数据/引用，由中台合成定位器转换。当前 S01 草案把设备模拟进程写成直接返回槽位，需在 S01 PR 中分层修订后才可据此做跨进程验收。
