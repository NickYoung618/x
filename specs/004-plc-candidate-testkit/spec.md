# Feature Specification: 虚拟下位机候选版本测试包

**Feature Branch**: `004-plc-candidate-testkit`
**Created**: 2026-09-17
**Status**: Implemented — scope and actual evidence in validation.md
**Input**: 先搭好框架，以便负责下位机的同学进行测试；继承 002 的独立模拟器联调和 003 的中台流程框架。

## User Scenarios & Testing

### User Story 1 - 持续验证当前联调基线 (Priority: P1)

中台与下位机开发者在新增测试工程后，仍能用同一入口验证 .NET 10 构建、全部实际测试、旧协议检查和独立双进程联调；缺失、跳过或失败的测试不能显示绿色。

**Independent Test**: 从干净构建执行统一入口，核对四个测试程序集和每项联调结果。

**Acceptance Scenarios**:
1. **Given** 当前包含四个测试程序集，**When** 执行统一入口，**Then** 每个程序集真实运行且全部通过，旧协议13组和双进程5场景各自记录。
2. **Given** 一个程序集未产生报告或有跳过，**When** 判定运行，**Then** 总结失败且保留本次证据。

### User Story 2 - 同学测试独立候选模拟器 (Priority: P1)

下位机开发者可以把自己发布的独立模拟器候选程序交给联调入口；在明确选择旧协议兼容测试后，入口启动该候选程序，使用中台真实 Modbus 客户端检查它，并留存候选二进制身份、Host 报文和设备日志。

**Independent Test**: 使用当前已知旧协议模拟器的另一个发布目录作候选，验证报告指向候选 DLL、5个双进程场景和故障/重连阻断；错误协议或缺少候选文件时，动作前拒绝。

**Acceptance Scenarios**:
1. **Given** 一个 .NET 10 旧协议候选 DLL，**When** 显式选择旧协议并运行，**Then** 隔离启动候选，完整输出来源哈希、13组旧检查、5个联调场景和本次目录。
2. **Given** 候选不兼容、缺文件或没有显式协议选择，**When** 运行，**Then** 返回失败；不回退内置模拟器并假称候选已通过。

### Edge Cases

- 源码增加或移除测试工程，TRX 数量变化；同一测试程序集产生多份报告；全部跳过。
- 候选进程提前退出、未就绪、动作超时、设备失败、残留完成位、Unknown 后重连。
- 不得连接真实硬件；测试只启动本机候选模拟器并绑定回环地址。

## Requirements

### Functional Requirements

- **FR-001**: 测试入口必须验证锁定依赖还原、.NET 10 生产构建、当前解决方案每个测试程序集的实际执行与全通过。
- **FR-002**: 必须把旧协议自身检查、Host↔独立模拟器联调、V1.3正式契约和完整整盘四类结果分开记录；后两类本阶段保持 NOT RUN。
- **FR-003**: 候选测试必须显式指定旧协议版本，记录候选程序哈希，并使用候选本身而非内置程序执行联调。
- **FR-004**: Host 业务通信必须走 Modbus；HTTP 仅用于模拟器就绪、故障布置与独立证据；Unknown 后不得自动重发物理动作。
- **FR-005**: 每次运行应有独立证据目录；失败时保留日志并停止本次启动的子进程。
- **FR-006**: 指南须给下位机同学明确命令、输入、判定边界和回传证据；不得将旧协议通过写为 V1.3 通过。

## Success Criteria

- **SC-001**: 当前四个测试程序集全部计入报告，42项当前基线测试通过且无跳过；数量随真实解决方案演进，不能锁死在过去的3个程序集。
- **SC-002**: 候选 DLL 模式的正常、残留、明确失败、超时和 Unknown 重连五种场景均有 Host 与独立模拟器证据。
- **SC-003**: 错误协议选择或错误候选文件产生非零退出和清楚的失败报告，零个动作被执行。

## Assumptions

候选模式仅测试 2026-09-17 旧 V6 单寄存器16位快照协议，面向软件模拟器而非真实 PLC。候选程序由同学先自行发布；本入口检查它的运行时目标和二进制哈希，但不替候选源码证明构建过程。V1.3点表、会话序号与完整动作仍待下位机同学确认后添加独立测试档案。
