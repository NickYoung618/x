# Implementation Plan: V1.3 设备模拟

**Branch**: `plc-v13-device-20260917`
**Spec**: [spec.md](spec.md)
**Contract**: [全工位合同草案](../../docs/contracts/plc-v13-all-stations-v0.1.md)

## 技术路线

1. 在 `simulator/VirtualPlc` 内按显式合同版本选择 9 月 11 日模拟核心；V6 默认入口保持独立。只对回环端点开放测试动作。
2. 共用 PR #9 的 Application 端口、点表及串行 Modbus TCP 客户端；扩充有设备会话/命令身份的虚拟测试路径，完整保留 FC01/03/05/06/16 原始报文。合成扩展须另有合同标识，不改变原协议已定义值。
3. 独立 3D 进程交付可校验的固定帧/引用及采集轨迹。中台负责帧到槽位的转换，PLC 不生成业务结果。
4. 将 Host 的 S01 装配延至 F 位；动作按同一执行通道串行，未知阻断并保留现场事实。F 盘码和区域配置仍保持正确时序。
5. 以独立进程运行正常、故障、断线和重复命令场景，保存双方原始报文和设备轨迹；旧 V6 另行回归。

## 冻结门槛

虚拟命令承载与 3D 传输尚在询问用户；依赖它们的代码在决定确认后实现。真实 PLC 写动作始终需厂商点位与机械安全签认。测试合成坐标、帧和时限须在配置及证据中显式标记。

## 交付顺序

- 合同评审稿作为首个独立提交。
- 虚拟协议/独立 3D/Host 联调各自可审提交；最后统一锁定还原、Release 构建、测试和 Draft PR。
