# Feature Specification: 虚拟下位机接入与 V1.3 对齐（第一增量）

**Feature Branch**: `002-virtual-plc-integration`
**Created**: 2026-09-17
**Status**: Implemented — framework/legacy increment only; see validation.md；后续线上契约交下位机同学确认
**Input**: 用户要求复用本机快照，完成可复现构建测试、中台实际客户端与独立模拟器最小联调，先核对差异。

## User Scenarios & Testing

### User Story 1 - 复现已有组件 (Priority: P1)
团队成员从仓库获得有来源的模拟器，用单一入口构建生产目标并运行已有检查。
**Why this priority**: 消除依赖旧机器、旧框架和人工适配的验证条件。
**Independent Test**: 从干净输出目录执行验证，保留构建、检查及环境记录。
**Acceptance Scenarios**:
1. Given 已校验源码，When 构建验证，Then 主程序真实构建成功，旧协议13组逐项有结果。
2. Given 构建失败或未执行，When 汇总，Then 整体失败且不产生通过声明。

### User Story 2 - 中台真实通信 (Priority: P1)
中台开发者启动独立模拟器，通过中台设备适配执行最小准备与两个顺序定位动作，观察独立设备状态。
**Why this priority**: 证明中台通信路径与设备握手真实相连。
**Independent Test**: 中台进程与模拟器进程分离，保存请求响应、状态及设备动作日志。
**Acceptance Scenarios**:
1. Given 模拟器初态，When 准备并顺序定位两次，Then 每次观察新忙状态及完成，最终坐标匹配，各动作只执行一次。
2. Given 上次完成残留，When 启动新连接，Then 要求对账且不发新动作。
3. Given 设备失败或等待到期，When 当前动作收敛，Then 分别返回失败或未知、不重发、不进入下一动作。
4. Given 网络回复异常，When 客户端处理，Then 有界失败、废弃连接、不自动重放。

### User Story 3 - 评审对齐范围 (Priority: P2)
双方通过版本差异表确定后续接口决定，能分辨组件通过、架构对接通过与整盘通过。
**Why this priority**: 避免旧测试绿色掩盖协议和业务缺口。
**Independent Test**: 每个差异有来源、影响、待决项或本轮处置，验证报告三类结果分列。
**Acceptance Scenarios**:
1. Given 两份不一致点表，When 对比，Then 明确地址、数据类型、反馈关联及完整动作参数差异。
2. Given 旧随机业务兜底，When 中台联调，Then 不调用此接口、不输出质量判断。

### Edge Cases
端口占用、子进程提前退出、构建工具缺失、残留完成、设备返回失败、丢响应、错误事务/单元/长度、动作超时、外部取消。所有尝试留证据，清理仅限自己启动的进程。

## Requirements

### Functional Requirements
- **FR-001**: 保留来源校验及原规格；使用固定工具链，构建失败/未运行必须使验收失败。
- **FR-002**: 复用已有13组检查，明确其旧协议及旧失败策略范围。
- **FR-003**: 中台实际通信适配连接独立设备，控制面只用于布置及取证。
- **FR-004**: 同时仅一个动作；新忙状态前不接受完成；残留状态要求对账。
- **FR-005**: 失败、未知、完成分开，未知不自动重发或继续；通信等待有界。
- **FR-006**: 保存环境、构建、客户端交互、独立设备日志及结果；失败尝试不得覆盖。
- **FR-007**: 默认 Host 不自动连接或运动；工程联调必须显式选择旧协议模拟端点。
- **FR-008**: 分列旧协议、V1.3对接、整盘结果与双方未决项。

### Key Entities
- 来源快照：归档摘要、相对路径、原始文件校验。
- 兼容协议：版本名、能力边界、数值语义、动作握手。
- 联调结果：阶段、终态、坐标、请求轨迹和独立设备证据。

## Success Criteria

### Measurable Outcomes
- **SC-001**: 团队可用一条命令重现组件构建及13组检查，无手改源码步骤。
- **SC-002**: 正常、残留、失败、超时四类场景均有机器可读结果和设备侧证据。
- **SC-003**: 所有已识别接口差异有明确状态，零项未做验收被记为通过。
- **SC-004**: 默认启动不会产生任何设备动作。

## Assumptions
本轮仅兼容已观察旧协议，不冻结生产地址/单位。工程探针只用于隔离模拟器。
后续 Float32字序、会话序号、完整取放参数不影响本轮兼容实现，列入待双方确认表；不将其默认选项写进实现。
不包含整盘执行、扫码/3D/相机/算法、持久化、WPF或FullSim发布。依据共同章程和交接文档。
